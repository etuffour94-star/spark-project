# Spark Project

## 📌 Overview
This repository contains a hands‑on project demonstrating **Apache Spark** setup and usage on Windows with Anaconda Python, Java 17, and Hadoop winutils integration. It is designed for learning big data concepts, distributed processing, and workflow automation.

## 🚀 Features
- Spark configuration on Windows
- Hadoop winutils integration for filesystem compatibility
- Python scripts showcasing Spark transformations and actions
- CSV data ingestion and processing examples
- Notes and experiments for deeper Spark concepts

## 🛠️ Technologies Used
- Apache Spark 4.1.2
- Python (Anaconda environment)
- Java 17
- Hadoop winutils
- Git Bash

## 📂 Project Structure
- `deeper_concepts.py` → Spark transformations and actions in Python
- `md.csv` / `Md_summary.csv` → Sample datasets
- `sparktry.txt` → Notes and experiments
- `README.md` → Documentation
